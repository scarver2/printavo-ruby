# Security Policy

## Supported Versions

Security fixes are applied to the latest released version of `printavo-ruby`.
Upgrade to the current release before reporting behavior that may already have
been corrected.

## Reporting A Vulnerability

Do not open a public issue for suspected vulnerabilities, exposed credentials,
or sensitive Printavo response data. Use GitHub's
[private vulnerability reporting](https://github.com/scarver2/printavo-ruby/security/advisories/new)
to provide a description, reproduction steps, affected versions, and any known
mitigations.

Please remove real Printavo credentials and customer information from reports.
Sanitized examples are sufficient for initial triage. You can expect an initial
response within seven days.
